==============================================================================
  TrainingAssistant – Eigene Trainingspläne anlegen und importieren
==============================================================================

Ein Trainingsplan ist eine Textdatei im Format YAML (oder JSON). Sie beschreibt
deine Übungen und Workouts. Du fügst den Text in der TrainingAssistant-Karte ein:

    Reiter „Einstellungen“ → „Eigener Plan“ → Text einfügen → „Importieren“

Ist etwas falsch, zeigt die Karte genau an, wo (z. B.
„workouts/0/blocks/2/exercise: Übung 'kniebeuge' steht nicht im Katalog“).
Ein Plan mit gleichem Namen wird ersetzt – dein Verlauf bleibt erhalten.


==============================================================================
  1. Drei Wege zum eigenen Plan
==============================================================================

A) Vorlage anpassen (am einfachsten)
   Reiter „Einstellungen“ → „Vorlagen“ → eine Vorlage übernehmen → unter „Meine Pläne“ auf
   „Bearbeiten“. Der Text steht dann im Importfeld. Ändern (z. B. Gewichte,
   Übungen, Namen) und „Importieren“ drücken.

B) Mit ChatGPT, Claude o. Ä. erzeugen lassen
   Den Prompt aus Abschnitt 4 kopieren, unten deine Wünsche eintragen (Ziel,
   Tage pro Woche, Ausrüstung, Startgewichte) – oder einen vorhandenen Plan
   (Tabelle, Foto, PDF) anhängen und „Wandle den angehängten Plan um“ schreiben.
   Die Antwort (nur der YAML-Text) in das Importfeld einfügen.

C) Selbst schreiben
   Mit dem Beispiel aus Abschnitt 5 starten – es steht auch schon im Importfeld
   der Karte – und anpassen.


==============================================================================
  2. Aufbau eines Plans
==============================================================================

  schema_version: 1        immer 1
  name                     Name des Plans
  description              (optional) kurze Beschreibung
  defaults                 (optional) Pause und Progression für alle Übungen
  exercises                Übungskatalog: ID → Name, Ausrüstung, (Bild, Muskeln)
  workouts                 Workouts, werden reihum vorgeschlagen
    └ blocks               Abschnitte in fester Reihenfolge

  Blocktypen:
    warmup / cooldown      Aufwärmen / Cool Down, enden per Knopf
    sets                   Sätze einer Übung (z. B. 5×5, 3×8–12)
    circuit                Zirkel: alle Übungen nacheinander, mehrere Runden
                           (rounds) oder Runden bis die Zeit um ist (time_cap_s)
    interval               HIIT: Arbeit/Pause in Sekunden, zeitgesteuert
    flow                   zeitgesteuerte Abfolge, eigene Dauer je Übung (Yoga)

  Werte pro Satz:
    reps                   8  ·  { min: 8, max: 12 }  ·  max
    duration_s             statt reps: 30  ·  { min: 30, max: 45 }  ·  max
    weight_kg              Gewicht; weglassen = Körpergewicht
    per_side: true         pro Arm/Bein
    tempo: "3-0-1"         wird angesagt

  Pausen (Sekunden):
    rest_s                 zwischen Sätzen (sets)
    rest_after_exercise_s  zwischen Übungen im Zirkel
    rest_after_round_s     zwischen Zirkelrunden
    rest_after_s           nach dem ganzen Block

  Progression (Vorschläge fürs nächste Training):
    { type: double, increment_kg: 2.5 }   erst Wdh. bis zur Obergrenze, dann +Gewicht
                                         (braucht reps: { min, max })
    { type: linear, increment_kg: 2.5 }   alle Sätze geschafft → +Gewicht (z. B. 5×5)
    { type: reps, max_reps: 20 }          Körpergewicht: +1 Wdh. pro Training
    { type: none }                        keine Vorschläge

  Bilder: werden über den englischen oder deutschen Übungsnamen automatisch
  gefunden. Selbst festlegen mit image: <Bild-ID> (Ordnername aus
  https://github.com/yuhonas/free-exercise-db/tree/main/exercises) oder
  image: false für kein Bild.

  Muskelgruppen (für „Sätze pro Muskelgruppe“ und Erholung): automatisch über
  das Bild, oder selbst angeben, z. B. muscles: [hamstrings, glutes, back].
  Gruppen: chest, back, shoulders, biceps, triceps, core, quads, hamstrings,
  glutes, calves. muscles: [] = Ganzkörper, wird nicht gezählt.


==============================================================================
  3. Häufige Fehler
==============================================================================

  - Einrückung: nur Leerzeichen, keine Tabulatoren. Gleiche Ebene = gleiche
    Einrückung.
  - Kommas in der Kurzschreibweise { … }: Text mit Komma in Anführungszeichen,
    z. B.  note: "Langsam, kontrolliert"
  - Doppelpunkt mit Leerzeichen im Text ebenfalls in Anführungszeichen.
  - Jede Übung, die in einem Block vorkommt, muss unter exercises stehen.
  - Feste Wiederholungszahl (reps: 8) nicht mit type: double kombinieren –
    dort linear, reps oder none nehmen.
  - reps und duration_s nie gleichzeitig.


==============================================================================
  4. Prompt für ChatGPT, Claude & Co.
==============================================================================

Erstelle mir einen Trainingsplan im YAML-Format „TrainingAssistant Version 1“.
Halte dich exakt an diese Regeln und gib NUR den YAML-Code aus, ohne Erklärungen.

Oberste Ebene:
  schema_version: 1          (immer genau 1)
  name: <Text>
  description: <Text>        (optional)
  goal: hypertrophy | strength | endurance | general   (optional)
  defaults:                  (optional)
    rest_s: <Sekunden>
    progression: <Progression>
  exercises:                 Katalog, Schlüssel = ID in snake_case (a–z, 0–9, _)
    <id>:
      name: <Anzeigename>
      aliases: [<weitere Namen>]       (optional)
      equipment: bodyweight | dumbbell | kettlebell | barbell | band | machine | cable | other
      note: <Technik-Hinweis>          (optional)
      image: <Bild-ID aus free-exercise-db> (optional, sonst automatisch; false = kein Bild)
      muscles: [chest | back | shoulders | biceps | triceps | core | quads | hamstrings | glutes | calves]
                                       (optional, Hauptmuskeln; [] = Ganzkörper/keine)
  workouts:                  Liste
    - id: <snake_case>
      name: <Text>
      blocks: [<Block>, ...]

Block-Typen (Feld "type"), alle mit optional name und note:
  warmup / cooldown: duration_s?
  sets:     exercise (ID), sets ODER total_reps, <Satz-Werte>, rest_s?, rest_after_s?
  circuit:  rounds ODER time_cap_s, exercises: [{exercise, <Satz-Werte>}],
            rest_after_exercise_s?, rest_after_round_s?, rest_after_s?, tempo?
  interval: rounds, work_s, rest_s, exercises: [<ID>, ...], rest_after_s?   (HIIT, keine reps)
  flow:     exercises: [{exercise, duration_s, per_side?}], rounds?, rest_s?, rest_after_round_s?, rest_after_s?
            (zeitgesteuerte Abfolge, eigene Dauer je Übung – Yoga-Flows, 30-20-10; läuft von selbst)

Satz-Werte:
  reps: Zahl (8) ODER Bereich {min: 8, max: 12} ODER max
  duration_s: Sekunden (30) ODER Bereich {min: 30, max: 45} ODER max   – statt reps, nie beides
  weight_kg: Zahl in kg; weglassen bei Körpergewicht
  per_side: true, wenn „pro Arm/Bein“
  tempo: "3-0-1" (optional)
  progression: (optional, überschreibt defaults)

Pausen in ganzen Sekunden:
  rest_s = zwischen Sätzen (sets), rest_after_exercise_s = zwischen Übungen im Zirkel,
  rest_after_round_s = zwischen Zirkelrunden, rest_after_s = nach dem ganzen Block.

Sonderfälle:
  „X Minuten im Wechsel“      → circuit mit time_cap_s: X*60 statt rounds
  „so viele Sätze bis N Wdh.“ → sets mit total_reps: N statt sets, meist reps: max
  „Gewicht um 5–10 % erhöhen“ o. Ä. → als note am Block; ein wiederholter Durchgang
                                     ist ein eigener, zweiter Block

Progression:
  {type: double, increment_kg: 2.5}   nur mit reps-Bereich
  {type: linear, increment_kg: 2.5}   für feste reps mit Gewicht (z. B. 5x5, 8)
  {type: reps, increment: 1, max_reps: 20}   Körpergewicht: +1 Wdh., sobald alle Sätze geschafft
                                      (max_reps optional)
  {type: none}                        keine Vorschläge

Wichtig:
  - Jede verwendete Übung muss im Katalog "exercises" stehen.
  - Feste reps (z. B. 8) nie mit double-Progression kombinieren; ohne Gewicht type: reps nehmen.
  - Keine weiteren Felder als die oben genannten.
  - Texte (name, note, description) mit Komma oder Doppelpunkt in "Anführungszeichen" setzen.
  - Gängige Übungen bekommen gängige englische IDs (goblet_squat, push_up, pull_up) und
    englische Namen wie in gängigen Übungsdatenbanken – dann werden Bilder automatisch zugeordnet.
    Das Feld image nur setzen, wenn du die ID aus free-exercise-db sicher kennst.
  - Bei ungewöhnlichen oder selbst benannten Übungen muscles angeben (nur Hauptmuskeln, höchstens 3).

Meine Wünsche: <HIER BESCHREIBEN: Ziel, Tage pro Woche, Dauer, vorhandenes Equipment,
Startgewichte, Einschränkungen – oder: „Wandle den angehängten Plan um.“>


==============================================================================
  5. Beispielplan
==============================================================================

# ─────────────────────────────────────────────────────────────────────────────
#  Eigener Trainingsplan – Beispiel zum Anpassen
#  Alles hinter # ist Kommentar und wird ignoriert. Einrücken nur mit Leerzeichen.
#  Ausführliche Anleitung: Knopf „Anleitung (.txt)“ über diesem Feld.
# ─────────────────────────────────────────────────────────────────────────────

schema_version: 1                  # immer 1
name: Mein Plan                    # gleicher Name wie ein vorhandener Plan = dieser wird ersetzt
description: Zwei Workouts im Wechsel, 3×/Woche.

defaults:                          # gilt überall, wo nichts anderes steht
  rest_s: 90                       # Pause zwischen Sätzen (Sekunden)
  progression:                     # Vorschläge fürs nächste Training
    type: double                   # double = erst Wdh. steigern, dann Gewicht (+increment_kg)
    increment_kg: 2.5

# ── 1) Übungen ───────────────────────────────────────────────────────────────
#  ID (klein, ohne Leerzeichen) → Name. Über die ID wird dein Verlauf zugeordnet.
#  Bilder kommen automatisch über den Namen; sonst image: <Bild-ID> oder image: false.
exercises:
  kniebeuge:
    name: Kniebeuge
    equipment: barbell             # bodyweight, dumbbell, kettlebell, barbell, band, machine, cable, other
  liegestuetz:
    name: Liegestütze
    equipment: bodyweight
  rudern:
    name: Kurzhantelrudern einarmig
    equipment: dumbbell
    image: One-Arm_Dumbbell_Row
  plank:
    name: Plank
    equipment: bodyweight
  hampelmann:
    name: Hampelmann
    equipment: bodyweight
    image: false

# ── 2) Workouts ──────────────────────────────────────────────────────────────
#  Werden reihum vorgeschlagen (A, B, A, …). Jedes Workout besteht aus Blöcken.
workouts:
  - id: a
    name: Workout A
    blocks:
      - type: warmup               # Aufwärmen – endet per Knopf
        note: 5 Minuten locker bewegen.

      - type: sets                 # klassische Sätze einer Übung
        exercise: kniebeuge
        sets: 3
        reps: { min: 8, max: 12 }  # Bereich – oder feste Zahl (8) oder max
        weight_kg: 40              # weglassen = Körpergewicht
        rest_after_s: 120          # Pause nach dem ganzen Block

      - type: circuit              # Zirkel: alle Übungen nacheinander, mehrere Runden
        name: Oberkörper-Zirkel
        rounds: 3                  # oder time_cap_s: 300 = Runden bis die Zeit um ist
        rest_after_exercise_s: 30
        rest_after_round_s: 90
        exercises:
          - exercise: liegestuetz
            reps: 10
            progression: { type: reps }    # Körpergewicht: +1 Wdh. pro Training
          - exercise: rudern
            reps: { min: 8, max: 12 }
            per_side: true                  # pro Arm
            weight_kg: 14
          - exercise: plank
            duration_s: 45                  # Zeit statt Wiederholungen

      - type: cooldown             # Cool Down

  - id: b
    name: Workout B
    blocks:
      - type: warmup
      - type: sets
        exercise: kniebeuge
        sets: 5
        reps: 5
        weight_kg: 50
        progression: { type: linear, increment_kg: 2.5 }   # alle 5×5 geschafft → +2,5 kg
      - type: interval             # HIIT: zeitgesteuert, keine Wiederholungen
        rounds: 8
        work_s: 20
        rest_s: 10
        exercises: [hampelmann, liegestuetz]   # wechseln sich ab
      - type: cooldown
